

1.0.11
- Options (Main tab): move the "No unresolved field warning" and "RDP credential cleanup (ms)" settings directly below the "Connection options field"

1.0.10
- Warn when the configuration is loaded from the current working directory
- Options: right-click an application's icon cell to remove a set standard/custom icon and restore the default executable icon

1.0.9
- Secure RDP credential handling via the Windows Credential Manager API (no more password on the command line)
- Adaptive credential cleanup: wait for mstsc to be ready and always remove the temporary credential
- New configurable RDP credential cleanup delay (Options dialog and XML)
- Upgrade target framework to .NET Framework 3.5 (KeePass 2.59+)
- Enlarged Main settings tab and Options window
- Remove obsolete "Remote Desktop (Console)" connection option
- Resolve mstsc.exe via %SystemRoot% instead of a hardcoded path
- Robust settings file handling: wrap file streams in using blocks to guarantee handle release
- More robust executable directory resolution (UNC/network share safe, no crash when the entry assembly is unavailable)
- Fail-fast plugin loading: report load errors (including a missing embedded icon) via a clear message and abort cleanly; null-safe Terminate()
- Show the concrete reason when saving the configuration fails and keep the Options dialog open on save errors
- Connection start threads now work on an immutable snapshot of their input (no shared mutable state), set IsBackground before start
- Custom applications can now use a chosen KeePass icon (standard or custom icon) instead of always the executable icon (double-click the icon column in the Options grid); custom icons are stored database-independently as Base64 PNG in the plugin configuration, so they keep working regardless of which or how many databases are open
